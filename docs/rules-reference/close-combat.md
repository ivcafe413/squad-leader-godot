# Rules Reference — Close Combat

Scope: close combat rules needed for Scenario 1 only.

## Summary
- Resolved in the Close Combat Phase for any hex containing units from both sides at the end of the Advance Phase.
- Combat strength of all units in the hex is totaled per side and resolved similarly to fire combat, typically at more decisive odds/results than ranged fire.
