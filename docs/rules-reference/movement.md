# Rules Reference — Movement

Scope: movement rules needed for Scenario 1 only.

## Summary
- Each unit has a printed Movement Allowance (MF/MP) spent during its side's Movement Phase.
- Moving into a hex costs MF according to the terrain in that hex (see [los-and-terrain.md](los-and-terrain.md) for per-terrain costs).
- A unit may not move if it lacks enough MF remaining to enter the next hex, with the general exception that a unit may always move one hex per phase even if it can't afford the full cost (confirm exact rule/exception wording below).
- Stacking limits apply per hex (confirm max stack from rulebook).
