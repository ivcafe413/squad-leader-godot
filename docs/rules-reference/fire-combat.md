# Rules Reference — Fire Combat

Scope: fire combat rules needed for Scenario 1 only.

## Summary (rulebook §8–11, 17)
- A unit may fire once per player turn with its inherent firepower, except Close Combat which is separate (§8.2).
- Fire is directed uniformly at all occupants of the target hex (§8.3); a hex may be fired on any number of times per turn (§8.2).
- Units in the same hex firing separately roll separate dice; units combining fire on the same target must combine into one dice roll (§8.4–8.5).
- **Fire Groups (§8.6):** any units in the same or adjacent hexes may combine firepower factors into one attack against one target hex with a single dice roll.

### Firepower Modifiers (§9) — cumulative (§9.5)
- **Point Blank Fire (§9.1):** firepower doubled when target hex is adjacent to the firing unit.
- **Long Range Fire (§9.2):** firepower halved when target exceeds the firing unit's printed range (no attacks allowed beyond double the printed range).
- **Moving Fire (§9.3):** firepower halved if the firing unit moved that player turn (exception: flamethrowers, §22.8).
- **Area Fire (§9.4):** firepower halved when the target is under a Concealment counter.

### Fire Combat Resolution (§10)
1. Total the Fire Group's firepower factors, apply modifiers above.
2. Cross-index total firepower against the Infantry Fire Table column (rightmost column not exceeding the total).
3. Roll 2 dice, apply Terrain Effects Modifiers (TEM, below) and any leadership modifier, cross-index the adjusted roll against the chosen firepower column.
4. **Results (§10.6):** `KIA` = all units in target hex eliminated; `M` = all squads/leaders in hex take an immediate Morale Check (leaders check first); `(#)` = same as `M` but the number shown is added to the Morale Check dice roll; `–` = no effect.

### Terrain Effects Modifiers — target hex (§11.1, applies to Scenario 1's board-1 terrain only, §11.5)

| Target hex terrain | DR modifier |
|---|---|
| Open terrain, moving | −2 |
| Open terrain, non-moving | 0 |
| Woods, Shellhole | +1 |
| Wood Building | +2 |
| Stone Building | +3 |
| Wheatfield (moving or non-moving) | 0 |

(Hedge/wall modifiers in §11.2 don't apply — walls and hedges do not appear on board 1, §11.5.)

### Machine Guns (§17, if any appear in Scenario 1's OB)
- A squad may fire any one MG or two LMGs at no cost to its own firepower; combining other MG combinations forfeits the squad's own inherent firepower for that turn (§17.1–17.2).
- MGs have a *penetration* factor letting one dice roll/firepower resolve fire against multiple target hexes along the same LOS (§17.5), lost when firing across an elevation change (§2.8 — not relevant on flat board 1).
