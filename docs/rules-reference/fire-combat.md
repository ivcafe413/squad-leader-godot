# Rules Reference — Fire Combat

Scope: fire combat rules needed for Scenario 1 only.

## Summary
- Firing unit(s) may combine fire against a single target hex; total firepower is compared to the printed Combat Results Table (CRT) as an odds ratio (or fixed FP column, depending on system), then modified by range, terrain (TEM), and other modifiers.
- A die roll (DR) is cross-referenced against the resulting CRT column to produce a result (e.g. no effect, pin, morale check at some severity, casualties/elimination).
- Results are applied immediately, feeding into the morale subsystem ([morale.md](morale.md)).
