# squad-leader-godot
Open-source Godot implementation of the 1977 Avalon Hill board game by the same name. Supports hotseat and online play.

## Status
Planning stage. v1 targets **Scenario 1 only**; see [docs/GDD.md](docs/GDD.md) for scope.
